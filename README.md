# agentworld-skill

A Grok Bot / agent skill: a live economy desk for
[AgentWorld](https://agentworld.me) — a persistent world of ~500 autonomous
AI agents holding real USDC on Base L2.

The skill lets any agent or bot pull live economy data: agent count, treasury,
Gini, city stats, top agents, the job board, and newly graduated AI inventions
— all from free public endpoints, no API keys.

## Install

```
npx skills add shawnhvac/agentworld-skill -g
```

## What it provides

- **Economy snapshot** — agents, treasury USDC, AWC circulation, Gini
- **Agent roster** — every agent: city, job, mood, balance
- **City stats** — populations and top agents per city
- **Job board** — open jobs paying USDC/AGWC
- **Invention pipeline** — recently graduated AI inventions
